# Food, toxin, and cognition models

Research code for food–toxin movement experiments, patch occupancy analysis, and a spatial Namibia mortality model. The archive contains three related workflows:

| Workflow | Location | What it does |
| --- | --- | --- |
| Spatial model and parameter calibration | `scripts/python/` | Runs the hunger-structured Namibia model and its food/toxin variants. |
| Agent simulations and figures | `scripts/matlab/` | Runs synthetic food–toxin movement experiments and plots their results or Namibia output. |
| Patch occupancy analysis | `scripts/r/` | Analyzes and plots the included experimental patch counts. |

**Data availability:** The supplied archive contained code, but none of the external Namibia input files or previously generated simulation result files. The R patch counts are embedded in `scripts/r/experiment_patch_data.R`; the synthetic MATLAB experiments generate their own food and toxin fields. See [the Namibia input guide](data/namibia/README.md) for required data and formats.

## Python: Namibia model

Use Python 3.10 or later. From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate                 # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
```

Put the three required files described in `data/namibia/README.md` under `data/namibia/`, then run:

```bash
python scripts/python/run_model.py full
```

Available scenarios are `full`, `nofood`, `notoxin`, and `uniform_low_food`. The runner writes each scenario to `results/namibia/<scenario>/` by default. For an external dataset or another output location, use `--data-dir /path/to/data --output-dir /path/to/output`. `--no-plots` skips the map figures. Run `python scripts/python/run_model.py --help` for all input and runtime options. The uniform-food case retains the original constant value **0.025737**; `--uniform-food-level` can override it.

Parameter calibration uses Optuna and can be computationally expensive:

```bash
python scripts/python/calibrate_params.py --data-dir /path/to/data --n-trials 10
```

This calibrates the full model at mixed initial condition weight 0.8. Results and the Optuna database are kept in `results/` unless overridden. The four model files are kept separate because they implement distinct experimental variants.

## MATLAB: synthetic experiments and plots

Use MATLAB R2021b or later. Some maps use `knnsearch` and `tinv` from the Statistics and Machine Learning Toolbox, and one uses `imgaussfilt` from the Image Processing Toolbox. The Mapping Toolbox is optional for park boundary overlays. From the repository root in MATLAB:

```matlab
addpath(genpath(fullfile(pwd, 'scripts', 'matlab')));
run(fullfile('scripts','matlab','experiments','single_agent_movement_clean.m'));
run(fullfile('scripts','matlab','plots','figure_s_tau.m'));
```

The first script runs a reproducible single-agent example. It reads an optional `data/agent/single_agent_movement_input.csv` when present; otherwise it generates random increments with its fixed seed. The agent simulations save outputs to `results/agent/` and figures to `figures/agent/`. Plotting scripts read these result files, or the outputs of the Python Namibia scenarios, and save figures to `figures/namibia/` or `figures/agent/`. The `project_paths.m` helper resolves paths relative to this repository, so the files do not depend on their author's computer. Plot the Namibia outputs after running the corresponding Python scenarios.

Several comparison plots require *additional* `.mat` files for v2/v10 hunger conditions and toxin controls, which were absent from the supplied archive. The agent scripts can generate these by setting `AGENT_INITIAL_HUNGER` and `AGENT_TOXIN_MODE`; see [the workflow inventory](docs/WORKFLOWS.md) for the exact run order. The hunger time series plots additionally need `mean_hunger_timeseries.csv`, `hunger_distribution_snapshots.csv`, or `hunger_distribution_timeseries.csv`, which are not generated by the current Python model.

## R: patch counts

Install the R packages `tidyverse`, `car`, and `emmeans` once in your R environment. Then, from the repository root:

```bash
Rscript scripts/r/experiment_data_summary.R
Rscript scripts/r/experiment_abundance_summary.R
Rscript scripts/r/plot_experiment.R
```

Each script reads the same 40 recorded trials from `experiment_patch_data.R`. Summaries and plots are saved in `results/experiment/` and `figures/experiment/`. Set `EXPERIMENT_RESULTS_DIR` or `EXPERIMENT_FIGURES_DIR` to override those folders. The raw counts are included so this workflow needs no external data.

## Moving data and output directories

The Python runner accepts `--data-dir` and `--output-dir`; MATLAB uses these optional environment variables:

| Variable | Default |
| --- | --- |
| `NAMIBIA_DATA_DIR` | `data/namibia/` |
| `NAMIBIA_RESULTS_DIR` | `results/namibia/` |
| `NAMIBIA_FIGURES_DIR` | `figures/namibia/` |
| `AGENT_RESULTS_DIR` | `results/agent/` |
| `AGENT_FIGURES_DIR` | `figures/agent/` |

`results/`, `figures/`, and raw `data/namibia/` files are excluded from Git by default. Do not assume the inputs can be redistributed; obtain permission from the dataset owner before uploading them.
